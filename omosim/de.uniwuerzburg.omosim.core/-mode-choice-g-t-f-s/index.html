ModeChoiceGTFS

class ModeChoiceGTFS(hopper: GraphHopper, ptRouter: PtRouter, ptSimDays: Map<Weekday, LocalDate>, timeZone: TimeZone, withPath: Boolean, parameterReader: ParameterReader) : ModeChoice

Do mode choice with the mode options: FOOT, BICYCLE, CAR_DRIVER, CAR_PASSENGER, PUBLIC_TRANSIT Uses a multinomial logit model at its core.

Parameters

hopper

GraphHopper for routing

ptRouter

GTFS router

ptSimDays

Maps simulated weekday to a real date in the GTFS data.

timeZone

Time zone of GTFS information. Necessary because GraphHopper works with time zone aware time.

withPath

Return the lat-lon coordinates of the car trips.
