ModeChoiceFast

class ModeChoiceFast(routingCache: RoutingCache, parameterReader: ParameterReader) : ModeChoice

Do mode choice with the mode options: FOOT, BICYCLE, CAR_DRIVER, CAR_PASSENGER, PUBLIC_TRANSIT Uses a multinomial logit model at its core.

The difference to ModeChoiceGTFS is that this does not use the travel time of each mode and takes the approximated car distance from the routing cache. Making it significantly faster.
