Building

class Building(val osmID: Long, val coord: Coordinate, val latlonCoord: Coordinate, var odZone: ODZone?, val inFocusArea: Boolean, var attractions: MutableMap<Int, Double>, val population: Double, val point: Point, var cell: Cell? = null, val osmProperties: BuildingProperties) : RealLocation, Clusterable

A building. Can be the location of an activity.

Parameters

osmID

OpenStreetMap ID

coord

Coordinates of centroid in model CRS (Distance unit: meters)

latlonCoord

coordinates in lat-lon

odZone

origin-destination zone (TAZ). Only relevant if OD-data is provided.

inFocusArea

is the building inside the focus area?

attractions

KEY: id, VAL: Attraction value of that building for the distance choice function with that id

point

Coordinates of the building as a geometry type

cell

Grid cell the building is inside in
